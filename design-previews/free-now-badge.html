What actually changes (Tailwind classes, kit/room-card.tsx)

font sizetext-caption (12px) → new text-[11px] micro size
You explicitly invited "smaller text" as an option — text-caption is currently this design system's smallest defined token, so going smaller means introducing a dedicated micro size for exactly this kind of dense overlay badge (not reusing it for body captions elsewhere). If you'd rather stay strictly within existing tokens, drop this one change and keep 12px — the padding/line-height/dot/shadow changes below still give a real, if smaller, improvement on their own.
paddingpx-2 py-0.5 → px-1.5 py-[3px], gap gap-1 → gap-0.75
line-heightadd leading-none
The biggest real lever: text-caption's inherited 1.5 line-height renders an 18px-tall line box around 12px text — that's the main hidden cause of the bulk, more than the padding itself. leading-none collapses it to match the font size.
dot sizesize-1.5 (6px) → size-1 (4px)
shadowshadow-sm → dropped
Less elevation = reads as quieter/supporting rather than a competing focal point.
backgroundbg-white/90 → bg-white/85, backdrop-blur kept
Still needed for legibility against all 8 category header colors — just slightly less opaque/flat now that the shadow is gone.
measured result−13.6% width, −22.7% height (≈33% smaller footprint), measured in-browser via getBoundingClientRect — not estimated
unchangedcolor tokens, dot+text pairing (color is never the only signal for availability)
